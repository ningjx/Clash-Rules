生成 ProxyProvider 配置

Cloudflare Worker 不下载服务商订阅。生成的配置把订阅地址交给 OpenClash / Mihomo，由你的设备直接拉取节点。请使用 Mihomo 内核。

每行一个 HTTP/HTTPS 地址，最多 8 个。可写成“名称,地址”来指定 Provider 名称。
